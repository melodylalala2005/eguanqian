# 01 · 项目背景与市场分析

## 政策背景

国家在「十四五」期间持续推动数字经济与金融科技深度融合，相关规划明确鼓励金融服务数字化转型与普惠金融体系构建。监管机构积极倡导金融知识普及与理性投资文化，为「财务健康管理」领域提供了明确的政策支持与方向指引。

- 人民银行等七部门：《推动数字金融高质量发展行动方案》
- 《数据要素×三年行动计划（2024-2026）》

## 社会背景

两大驱动趋势：

1. **移动互联网与智能终端全面渗透**——消费、账单与交易行为高度数字化，为自动化记账与精准用户画像奠定了数据基础。
2. **年轻群体「数字习惯强，财务意识弱」**——大学生、职场新人、自由职业者易于接受新技术、高度依赖便捷工具，但欠缺系统化的理财知识与长期财务规划能力。

这共同催生了市场从「工具化记账」向「智能化、互动式财务管理与理财启蒙」升级的迫切需求。

## 目标用户与调研

以 18-50 岁的年轻到中年群体为主，包括大学生、职场人士及自由职业者：数字化习惯强，财务意识与规划能力不足。

我们对 **467 名互联网用户**（18-50 岁、各收入段）进行了线上问卷：

**记账工具使用情况**

- 经常使用：28%
- 偶尔使用：42%
- 未使用：30%

**最大痛点**（多选）

| 痛点 | 占比 |
| --- | --- |
| 记账操作太复杂 | 68% |
| 知道应当记录，但总是坚持不下去 | 54% |
| 即使记录也没法清晰看到自身财务状况 | 47% |
| 没有必要专门记账 | 14% |
| 不如手动记账 | 8% |

**理财启蒙**

- 61% 希望「能有工具帮我开始理财」
- 49% 表示「如果自动分析收支＋给建议，我愿意用」
- 16% 表示「愿意为智能财务分析服务付费」

## 蓝海机遇

### 1. 从被动记录到主动规划的体验升级

传统记账应用解决了「钱花在哪里」的问题，但无法回答「我该如何改善」。用户迫切需要基于自身数据获得个性化的财务健康诊断、预算规划及消费优化建议。鹅管钱通过引入「AI 理财专家」角色，实现从记录工具向规划伙伴的价值跃迁。

### 2. 面向年轻群体的理财启蒙新市场

年轻用户普遍拥有理财意愿但缺乏入门路径，对传统金融内容的复杂性存在畏难情绪。鹅管钱以高频记账场景为切入点，通过 AI 陪伴与角色化互动，将财务知识教育无缝融入日常管理。

### 3. 赋能金融机构的 C 端服务潜力

互联网银行及中小型金融机构普遍面临用户财务数据维度单一的挑战：缺乏线下网点和深度客户关系，主要依赖信贷和基础交易数据，难以获取反映用户财务健康度（储蓄率、债务结构、预算遵从度）的多维信息。在用户明确授权基础上，鹅管钱可生成匿名化财务健康画像与信贷需求预测，帮助金融机构提升风控效能与精准营销能力，开辟 B 端合作渠道。
